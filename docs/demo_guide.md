# 🎬 YieldSense AI — Demonstration & Handover Guide

> Step-by-step end-to-end demonstration guide for evaluating YieldSense AI.

---

## 📋 Pre-Demo Checklist

1. **Start Services (Docker Compose or Local)**:
   ```bash
   # Option A: Local Docker Compose Stack
   docker compose up --build -d

   # Option B: Manual Local Services
   cd backend && python -m uvicorn main:app --reload --port 8000
   cd frontend && npm run dev
   ```

2. **Verify Endpoints**:
   - Frontend Application: [http://localhost:3000](http://localhost:3000)
   - Backend API Docs: [http://localhost:8000/docs](http://localhost:8000/docs)
   - Backend Health Check: [http://localhost:8000/api/v1/health](http://localhost:8000/api/v1/health)

## 🚀 Step-by-Step Demonstration Flow

### 1. Landing Page & Public Navigation
- Open [http://localhost:3000](http://localhost:3000).
- Highlight the modern UI, dark mode toggle, system status indicator, and responsive layout.
- Click **Get Started** or **Sign In**.

### 2. User Authentication & Multi-Tenant Session
- Click **Sign Up** to create a test farmer account or **Log In** with existing credentials.
- Note the single-refresh token lifecycle that cleanly initializes the user session.
- Navigate to `/profile` to view account details and role assignment (`Farmer` or `Admin`).

### 3. Farm Setup & Multi-Tenant Management (`/farms`)
- Navigate to **Farm Management** (`/farms`).
- Click **+ Add New Farm**.
- Fill in parameters:
  - Farm Name: `Green Valley Farm`
  - Location: `Punjab, India`
  - Area: `12.5 hectares`
  - Primary Crop: `Wheat`
  - Soil Attributes: `pH 6.8`, `Nitrogen 90`, `Phosphorus 45`, `Potassium 40`
- Submit to create the farm. Confirm data is stored in Google Firestore under tenant isolation.

### 4. Interactive Crop Yield Prediction (`/prediction`)
- Navigate to **AI Prediction** (`/prediction`).
- Fill in parameters:
  - Crop: `Wheat` | Season: `Rabi` | State: `Punjab`
  - Area: `12.5 ha` | Rainfall: `850 mm` | Temperature: `22.5°C`
  - NPK: `90 / 45 / 40` | Soil pH: `6.8`
- Click **Generate Yield Forecast**.
- Observe output:
  - Predicted Yield in tons/hectare (`e.g. 4.25 tons/ha`).
  - Model confidence indicator (`High`) and R² score (`0.9860`).
  - Live soil health summary and weather integration.
  - Automatic saving to prediction history log.

### 5. Farm Advisory Panel (`/farms/[id]`)
- Return to **Farms** and click into `Green Valley Farm`.
- Inspect the live **Farm Advisory Panel**:
  - **Risk Level Badge**: `Low Risk` (or `Medium`/`High` depending on conditions).
  - **Identified Warning Signals**: Detailed list of soil, rainfall, or yield risks with specific corrective advice.
  - **Actionable Recommendations**: Plain-English numbered farmer advice generated by deterministic agronomic rules.

### 6. Live Analytics & Visualizations (`/analytics`)
- Navigate to **Analytics Dashboard** (`/analytics`).
- Explore four interactive Recharts charts:
  1. **Yield Trends**: Historical comparison over consecutive seasons.
  2. **Crop Comparison**: Multi-crop yield benchmarks.
  3. **Season Performance**: Seasonal distribution across Kharif, Rabi, and Zaid.
  4. **Scatter Analysis**: Rainfall vs. Yield correlation analysis.

### 7. Historical Prediction Audit (`/history`)
- Navigate to **Prediction History** (`/history`).
- Filter records by crop or search by farm name.
- Click **View Details** to trigger the modal detail view.

### 8. Report Generation & PDF/CSV Downloads (`/reports`)
- Navigate to **Reports** (`/reports`).
- Click **Generate Production Report**.
- Download **PDF Report**: Open the generated ReportLab PDF featuring executive summary, KPI grid, agronomic recommendations, and risk breakdown.
- Download **CSV Export**: Inspect raw prediction history tabular data.

### 9. Dedicated Admin Control Center (`/admin`)
- Log in with an account having `role: "admin"`.
- Navigate to **Admin Console** (`/admin`).
- View system-wide KPIs (Total Users, System Farms, Total Predictions, System Reports).
- Manage user roles (`Farmer` ↔ `Admin`).
- Inspect live system audit stream and ML model health metrics.
