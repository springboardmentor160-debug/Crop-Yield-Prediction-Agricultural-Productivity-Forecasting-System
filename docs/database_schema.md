# Database Schema

YieldSense AI uses SQLAlchemy with PostgreSQL for storing user accounts and crop-yield prediction history.

---

## 1. Users Table

The `users` table stores registered users and their authentication information.

| Column | Data Type | Constraints | Description |
|---|---|---|---|
| id | Integer | Primary Key, Indexed | Unique user identifier |
| name | String(100) | — | User's name |
| email | String(100) | Unique | User's email address |
| password | String(255) | — | Securely stored password hash |
| role | String(20) | — | User role such as Farmer |

---

## 2. Predictions Table

The `predictions` table stores the crop-yield prediction history generated by YieldSense AI.

| Column | Data Type | Constraints | Description |
|---|---|---|---|
| id | Integer | Primary Key, Indexed | Unique prediction identifier |
| user_email | String(100) | — | Email of the user who generated the prediction |
| crop | String(100) | — | Crop used for the prediction |
| rainfall | Float | — | Rainfall value used by the prediction system |
| pesticides | Float | — | Pesticide usage value |
| temperature | Float | — | Temperature value used for prediction |
| ph | Float | — | Soil pH value |
| estimated_yield | Float | — | Predicted crop yield |
| risk | String(50) | — | Overall agricultural risk level |
| recommendation | String(500) | — | AI-generated recommendation |
| created_at | DateTime | Default: current UTC time | Date and time of prediction |
